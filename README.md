# 📋 Team4prj - 투두리스트가 있는 게시판

학원에서 배운 기술을 활용하여 제작한 투두리스트 기능이 포함된 게시판 프로젝트입니다.

## 소개
* 프로젝트명: Team4prj (투두리스트가 있는 게시판)
* 개발 형태: 4인 1조 팀 프로젝트
* 개발 기간: 1일
* 목적: 팀 협업 및 복합 기능 구현 실습

## 사용 기술
* Language: Java 17
* Framework: Spring Boot
* Database: MariaDB
* Frontend: HTML
* Template Engine: Thymeleaf

## 주요 기능

### 게시판 기능
* 게시글 작성
* 게시글 조회
* 게시글 수정
* 게시글 삭제

### 투두리스트 기능
* 할 일 목록 관리
* 할 일 추가
* 할 일 완료 처리
* 할 일 삭제

### 통합 기능
* 게시판과 투두리스트 연동
* 사용자별 할 일 관리
